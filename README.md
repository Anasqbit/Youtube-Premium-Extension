# YouTube Premium Plus | يوتيوب بريميوم بلس

An awesome Chrome Extension that enhances your YouTube experience by simulating premium features, returning dislikes, adding a powerful downloader, and much more!

## 🇺🇸 English Description

### ✨ Features
* **Premium Logo:** Emulates and displays the official YouTube Premium logo.
* **Return Dislike:** Brings back the dislike count on all YouTube videos.
* **Video & MP3 Downloader:** Download videos and audio (MP3) tracks directly from YouTube.
* **Speed Controller:** Gain full control over playback speed up to 10x.
* **Dual Language Support:** Fully localized in both English and Arabic.

### 🛠️ How to Install (Locally)
1. **Download** or clone this repository to your local machine.
2. Open Google Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** (toggle the switch in the top right corner).
4. Click on **Load unpacked** (top left button).
5. Select the folder containing this project (the folder that has `manifest.json`).
6. Enjoy your upgraded YouTube experience!

## 🇦🇪 الوصف باللغة العربية

### ✨ الميزات
* **شعار بريميوم:** محاكاة وإظهار شعار يوتيوب بريميوم الرسمي.
* **إرجاع زر الديسلايك:** إظهار عدد الديسلايكات الحقيقي على الفيديوهات.
* **تحميل الفيديوهات والصوت:** تحميل مقاطع الفيديو والملفات الصوتية (MP3) مباشرة من يوتيوب.
* **متحكم السرعة:** التحكم الكامل بسرعة تشغيل الفيديو لتصل حتى 10 أضعاف (10x).
* **دعم لغوي كامل:** واجهات الإضافة متوفرة باللغتين العربية والإنجليزية بالكامل.

### 🛠️ طريقة التثبيت التلقائي (يدوياً)
1. **حمّل** المشروع كملف مضغوط وفك الضغط عنه، أو قم بعمل Clone للمستودع على جهازك.
2. افتح متصفح جوجل كروم واذهب إلى الرابط: `chrome://extensions/`.
3. قم بتفعيل **وضع مطور البرامج (Developer mode)** من الزاوية العلوية اليمنى.
4. اضغط على زر **تحميل نسخة غير معبأة (Load unpacked)** في الزاوية العلوية اليسرى.
5. اختر المجلد المحتوي على المشروع (المجلد الذي يوجد بداخلة ملف `manifest.json`).
6. استمتع بميزات يوتيوب الجديدة!
